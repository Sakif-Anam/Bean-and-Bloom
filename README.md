# ☕ Bean & Bloom Café

A modern, responsive café website designed for **Bean & Bloom Café**, featuring a warm and cozy aesthetic to showcase coffee, tea, freshly baked pastries, and the café's story.

🌐 **Live Website:** [Bean & Bloom Café](https://sakif-anam.github.io/Bean-and-Bloom/)

## 📌 About the Project

Bean & Bloom Café is a simple and elegant café landing page built to provide visitors with an enjoyable browsing experience. The website highlights the café's identity, introduces its menu, shares its story, and provides essential contact and location information.

The design focuses on a welcoming atmosphere, clean layout, and easy navigation.

## ✨ Features

- **Home Section:** Welcoming hero section with an introduction to the café.
- **About Section:** Showcases the café's story, values, and atmosphere.
- **Menu Section:** Displays coffee, tea, cold beverages, and freshly baked items with prices.
- **Contact Section:** Provides café location, opening hours, phone number, and email.
- **Responsive Design:** Designed to provide a smooth browsing experience across different screen sizes.
- **Easy Navigation:** Simple navigation links for accessing different sections of the website.

## 🛠️ Technologies Used

- **HTML5** – Website structure and content.
- **Tailwind CSS** – Styling, layout, and responsive design.
- **Git & GitHub** – Version control and project hosting.
- **GitHub Pages** – Deployment and live hosting.

## 🚀 Getting Started

Follow these steps to run the project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/Sakif-Anam/Bean-and-Bloom.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Bean-and-Bloom
   ```

3. Open `index.html` in your browser.

No additional installation or build process is required.
